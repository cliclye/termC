# Keyboard shortcuts

Shortcuts also appear in the command palette (`⌘K`) and in Settings → Shortcuts. `⌃` (Control) combos always go to the shell, so `⌃C`, `⌃R` and friends behave normally.

## General
| Action | Shortcut |
|---|---|
| Command palette / AI command | `⌘K` (also `⇧⌘P`) |
| AI: generate shell command | `⇧⌘K` |
| Settings | `⌘,` |
| Plugin store | `⇧⌘X` |
| Screenshot into terminal (global, configurable) | `⇧⌘S` |

## Tabs
| Action | Shortcut |
|---|---|
| New tab | `⌘T` |
| Close tab | `⇧⌘W` |
| Next / previous tab | `⇧⌘]` / `⇧⌘[` |
| Go to tab 1–8 / last | `⌘1`–`⌘8` / `⌘9` |
| Rename tab | double-click the tab |

## Panes
| Action | Shortcut |
|---|---|
| Split right | `⌘D` |
| Split down | `⇧⌘D` |
| Close pane | `⌘W` |
| Zoom / restore pane | `⇧⌘↩` |
| Equalize sizes | `⌥⌘=` |
| Focus left / right / up / down | `⌥⌘←` `⌥⌘→` `⌥⌘↑` `⌥⌘↓` |

## Workspaces
| Action | Shortcut |
|---|---|
| New workspace | `⇧⌘N` |
| Open folder as workspace | `⌘O` |
| Next / previous workspace | `⌥⌘]` / `⌥⌘[` |
| Go to workspace 1–9 | `⌥⌘1`–`⌥⌘9` |

## Terminal
| Action | Shortcut |
|---|---|
| Find | `⌘F` |
| Clear | `⇧⌘L` |
| Copy / paste | `⌘C` / `⌘V` |
| Insert file path (@-mention) | `⌘P` |
| Font size bigger / smaller / reset | `⌘=` / `⌘-` / `⌘0` |

## Panels
| Action | Shortcut |
|---|---|
| File browser | `⌘B` |
| Git | `⌘G` |
| Run commands | `⇧⌘R` |
| AI sessions | `⇧⌘A` |
| Dev server preview | `⇧⌘B` |
| Toggle sidebar | `⌘\` |

## Inside the palette and pickers
| Action | Key |
|---|---|
| Move | `↑` `↓` (or `⌃N` / `⌃P`) |
| Run / insert | `↩` |
| Ask AI | `Tab` |
| Insert absolute path (file picker) | `⌘↩` |
| AI result: run / insert without running | `↩` / `⌘↩` |
| Close | `Esc` |

Plugins can add their own shortcuts. For example, Snippets adds `⌥⌘U` (insert UUID) and `⌥⌘I` (insert snippet).
